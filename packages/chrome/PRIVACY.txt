Wan30 MCP Setup privacy disclosure

This extension does not handle user data.

It does not collect, store, transmit, or sell personal information, browsing history, page content, authentication information, or access tokens. It does not use analytics, remote code, or host permissions. It does not request Chrome permissions.

The platform choice and service-origin text exist only in the open extension page. They are used to build setup text on that page. A copy button places the visible text on the clipboard. Closing the page discards what was typed. The extension does not write it to disk and does not send it to Wan30, NotUsingGithub, Google, or any other party.

Links to wan30.video and https://github.com/NotUsingGithub/wan30-mcp open in a new browser tab only after a click. The extension itself does not call those sites.

Public author: Wan30 / NotUsingGithub.

This disclosure is this file, packages/chrome/PRIVACY.txt, in the public repository NotUsingGithub/wan30-mcp. It is not a page on wan30.video, and this extension does not deploy a website. If the Chrome Web Store dashboard requires a privacy-policy URL, use the GitHub blob for this file. That URL only identifies this text. It does not mean the store has accepted the extension.
